# More Designs and Websites

## Getting help

The quickest way to an answer is to ask someone. The
[JSCAD user group](https://openjscad.xyz/forum.html) is active and most questions get
answered the same day. For a back-and-forth, the
[JSCAD Discord](https://openjscad.xyz/discord.html) is the place.

The [JSCAD Community](https://github.com/jscad-community) organisation on GitHub
collects projects from users, and is a good place to see how other people structure
real designs.

## Designs to learn from

Reading someone else's design is the fastest way past a sticking point. There is a
broad collection on [Thingiverse](https://www.thingiverse.com/search?q=jscad), and
these people publish theirs:

- [Designs](https://github.com/gilboonet/designs) by @gilboonet
- [Designs](https://github.com/z3dev/designs) by @z3dev
- [JSCAD gallery](https://github.com/danmarshall/jscad-gallery) by @danmarshall
- [JSCAD models](https://github.com/tspspi/jscadmodels) by @tspspi
- [Nuts and bolts](https://github.com/johnwebbcole/jscad-hardware) by @johnwebbcole
- [JSCAD threadlib](https://github.com/receter/jscad-threadlib) by @receter

## Sites built with JSCAD

JSCAD is often embedded as a component rather than used as an application — these
sites all drive it from their own interface:

- [Bit By Bit Developers](https://bitbybit.dev/)
- [Cadhub](https://cadhub.xyz/)
- [ParaDrone: AutoPilot for Parachutes](https://paradr.one/)
- [Prusa Face Shield RC3 Modifier](https://mod.seblee.me/)
- [BuildBee](https://makecode.buildbee.com/)
- [RC Wing Design Tool](https://rcplanediy.com/)

## Applications

- **Rukkou** — interactive designs by @samuelwang48, on the App Store
- [jscad-now](https://github.com/danmarshall/jscad-now) — interactive viewer by
  @danmarshall

## Integrations

If you are wiring JSCAD into something of your own, these show how:

- [Vue components](https://github.com/z3dev/vue-components)
- [jscad-react](https://github.com/kenianbei/jscad-react)
- [Observable notebook](https://observablehq.com/@danmarshall/hello-jscad)
- [VS Code viewer](https://github.com/crysislinux/vscode-openjscad)

*These projects are maintained by their authors, and most were written against JSCAD
v2. Check which version one targets before adopting it.*
